# Domain docs

Before design or implementation, read:

- `SLACK_AGENT_SPEC.md` for v1 decisions and component contracts
- `SLACK_AGENT_HANDOFF.md` for M1 scope
- `CONTEXT.md` for canonical domain language
- `docs/adr/README.md` then the relevant ADRs. Treat superseded ADRs as history.

These files are created lazily as terminology and decisions settle.

Use glossary terminology consistently and explicitly flag anything that contradicts an ADR.
